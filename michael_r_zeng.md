## Project pitch

I want to use frontier models to optimize and accelerate computer algebra software such as SageMath, Macaulay2, and Julia's algebra packages. Starting with a small set of representative computations, I would profile bottlenecks and ask models to propose changes to algorithms, data structures, or implementation details. Each change would be checked for mathematical correctness and benchmarked for runtime and memory use on examples beyond those used during development. The aim is to produce useful patches and a reproducible record of which model-assisted changes actually help.
