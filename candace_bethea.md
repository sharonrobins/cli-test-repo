I am excited to be at this conference to learn about the most promising ways to use LLMs in my research; I'm currently just using it for things like literature searches and working through examples. 

Example problem: I want to create a companion tool for reading a paper. I want a tool that takes a paper and generates examples of the main theorems. For each theorem, I want three examples: 1. A simple example, 2. a counterexample that would exist if some assumptions were relaxed or in a very similar but related context of the theorem (e.g., if we try the main theorem that holds over C over a non-closed field), and 3. a more complicated example. The examples should be worked out in detail and should render in html. It should not use the same examples that are already in the paper if the paper already contains examples. The tool should also return any interesting ideas or possible new research directions that it encountered when generating the examples if they come up. These should be returned as a concise, but precise, bulleted list, not lengthy detail.
